Kebijakan Privasi Brankas

Berlaku sejak 27 November 2026

Brankas adalah password manager self-hosted di brankas.site yang dijalankan oleh pemilik servernya sendiri. Halaman ini menjelaskan data apa yang disimpan, bagaimana data itu dilindungi, dan bagaimana integrasi Google Drive dipakai.

Ringkasnya: isi vault dienkripsi di perangkatmu sebelum dikirim ke server. Server, admin, maupun pihak lain tidak bisa membaca password, catatan, kunci, atau lampiranmu. Tidak ada iklan, pelacakan, atau penjualan data.

1. Data yang disimpan

  • Username yang kamu pilih saat mendaftar.
  • Vault terenkripsi berisi item (login, kartu, identitas, catatan, SSH key, API key, folder). Dienkripsi AES-256-GCM dengan kunci yang diturunkan dari master password di browser.
  • Lampiran terenkripsi. Setiap file dienkripsi di browser dengan kunci acak sendiri; server hanya mengetahui ukurannya.
  • Data verifikasi login: salt dan hash scrypt dari kunci autentikasi. Master password tidak pernah dikirim maupun disimpan.
  • Data sesi: hash token sesi, waktu login, alamat IP, dan jenis browser, untuk keamanan dan pembatasan percobaan login.

2. Penggunaan data

Data hanya dipakai untuk menjalankan layanan: masuk ke akun, menyimpan dan menyinkronkan vault antar perangkatmu, serta melindungi akun dari penyalahgunaan. Data tidak dibagikan, dijual, atau dipakai untuk iklan.

3. Integrasi Google Drive (Brankas Backup)

Pemilik server memakai aplikasi Google "Brankas Backup" untuk menyimpan salinan cadangan database server ke Google Drive milik pemilik server sendiri.

  • Izin yang diminta hanya https://www.googleapis.com/auth/drive.file: akses ke file yang dibuat oleh aplikasi ini saja. Aplikasi tidak dapat melihat, membaca, atau mengubah file lain di Google Drive.
  • Yang diunggah hanyalah file backup database Brankas yang isinya sudah terenkripsi.
  • Data dari Google tidak dibagikan ke pihak ketiga, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI/ML. Penggunaan data yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.
  • Akses dapat dicabut kapan saja di myaccount.google.com/permissions.

4. Layanan pihak ketiga

  • Cloudflare Turnstile memverifikasi bahwa yang masuk atau mendaftar adalah manusia. Lihat kebijakan privasi Cloudflare.
  • Google Fonts memuat huruf tampilan aplikasi.

5. Penyimpanan & penghapusan

Data disimpan di server milik pemilik Brankas selama akun aktif. Kamu dapat menghapus akun beserta seluruh isi vault dan lampiran kapan saja melalui Pengaturan → Hapus akun. Salinan cadangan terenkripsi dihapus otomatis sesuai masa simpannya (±6 bulan di server, ±12 bulan di Google Drive).

6. Keamanan

Koneksi selalu melalui HTTPS. Karena enkripsi end-to-end, master password tidak dapat direset: bila lupa, isi vault tidak dapat dipulihkan oleh siapa pun.

7. Kontak

Pertanyaan tentang privasi atau penghapusan data dapat disampaikan kepada admin server Brankas yang mengundangmu.
